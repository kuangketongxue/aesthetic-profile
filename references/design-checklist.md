# 画像 → 设计决策对照表

> 画像给的是方向，这张表负责把方向变成**能写进代码的数值**。
> 原则：宁可给区间并在交付时说明依据，也不要给一个精确数假装算出来的。

## 一、配色

先从 `palette.primary` 直接取色，不要自创。若为空，按轴推导：

| 轴 | 取值 | 主色方向 | 底色 | 文字 |
|---|---|---|---|---|
| `temperature` | 0-30 | 橙/琥珀/砖红/暖褐 | 米白、暖灰 | 深褐 near-black |
| | 31-60 | 中性灰蓝、橄榄 | 中性 | 中性 |
| | 61-100 | 靛蓝/群青/青绿/紫 | 冷调深色或冷白 | 冷灰白 |
| `brightness` | 0-30 | 亮色只占 ≤10% 面积 | L* ≤ 25 | 浅色，对比 ≥7:1 |
| | 31-70 | 中调 | L* 40-90 | 对比 ≥4.5:1 |
| | 71-100 | 主色需加深 | 白/浅灰 | 深色文字 |

搭配硬指标（不依赖画像，属于底线）：

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1
- 主色不超过 3 个；点缀色 1 个，面积 ≤10%
- 深色主题不要纯黑 `#000` + 纯白 `#fff`（刺眼），用 `#0b1020` 级深蓝黑 + `#e8ecf5` 级灰白
- 需要长时间阅读的界面，饱和度整体压 10-15%

## 二、明暗与层次

`axes.brightness` 低（暗调）时：

- 用**明度差**做层次，不要用彩色描边堆砌
- 卡片底色比背景亮 4-8%，不要靠投影（暗底投影几乎不可见）
- 分隔线透明度 8-12%，不要硬线条

`axes.density` 低（极简）时：

- 一屏只留一个视觉焦点
- 删掉所有「装饰但没有信息」的元素：多余分割线、图标底框、渐变描边
- 段落行高 1.7-1.9，标题与正文间距 ≥ 正文字号 ×1.6

## 三、找图

1. 先拼关键词：`keywords.positive` 取 2-3 个 + 场景词（`wallpaper` / `portrait` / `texture`）
2. 排除词用 `keywords.negative`
3. 图源优先级（中国网络实测）：Unsplash 直链最快 → Pexels → 其他
4. **下载到本地再用相对路径引用**，不要外链（会裂图，也会因链接失效长期腐烂）
5. 每张图必须在本地验证：HTTP 200 + 能解码 + 实际看过内容

图片合规：Unsplash / Pexels 官方 License 允许免费商用、署名非强制；仍建议在页面标注来源。

## 四、字体

- 中文正文：思源黑体 / 苹方 / 系统默认（不要用花体标题撑场面）
- 字号阶梯固定：12 / 14 / 16 / 20 / 26 / 34 / 44（不要临时造第 8 个层级）
- 长文正文 16-18px，行高 1.7-1.8；每行 30-40 个汉字
- 数字用等宽或 `font-variant-numeric: tabular-nums`，避免跳动

## 五、场景差异（不要互相套用）

| 场景 | 关键约束 | 常见错误 |
|---|---|---|
| 网页首屏 | 背景图必须让文字可读 → 加遮罩或压暗 | 图美但标题读不清 |
| 壁纸 | 图标区要留低细节区域；边缘避开高对比 | 中心一朵花，图标全看不清 |
| 头像 | 小尺寸下要能认出来 → 单主体、干净背景 | 细节过多，缩到 48px 成一团 |
| 海报 | 一个主张 + 一个视觉锚点 | 信息全塞满，没有主次 |
| PPT | 每页一个结论，图占 ≤60% 面积 | 每页都配大图，内容被挤压 |
| 文档封面 | 留白足够放标题 | 满版图压字 |

## 六、交付前自检（逐条打勾）

- [ ] `hard_rules` 每条都满足
- [ ] 配色取自 `palette`，没有自创主色
- [ ] 正文对比度达标
- [ ] 图片本地化、能打开、实际看过
- [ ] 只有一个视觉焦点
- [ ] 场景约束（见上表）都满足
- [ ] 交出去时说明了「依据画像哪几条」，方便他反驳
